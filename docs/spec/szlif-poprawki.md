# Szlif: drobne poprawki

Lista zadań uzgodniona z autorem; odhaczana przy scaleniu. Sesja wznawia od pierwszej
nieodhaczonej pozycji.

## Karty

- [ ] Karta stanu: zasady w sekcji z nagłówkiem „Opis”, jak opis na karcie przedmiotu, bez inicjału
  zwoju. Kontrolka inicjału zostaje w Galerii.
- [ ] Proza: twarda nowa linia (Enter w tekście wpisu) zaczyna następną linię trochę niżej niż zwykłe
  zawinięcie — ok. 1/3 wysokości linii, wyraźnie mniej niż pusta linia. Także obok inicjału.
- [ ] Miecz worpalny dostaje podtyp z podręcznika („dowolny miecz zadający obrażenia cięte”). Gdy rząd
  tagów zawija się i wyciąga nagłówek ponad obrazek — tagi w jednej linii, ostatni ucięty „…” i pełny
  po najechaniu.
- [ ] Pełny tytuł po najechaniu zostaje, dopóki wskaźnik jest nad którąkolwiek jego częścią; da się go
  zaznaczyć w całości, kliknięcie go nie zamyka.

## Ikony

- [ ] Ikony stanów wymienione na jeden spójny zestaw o poziomie szczegółu czaszki (Lucide `skull`):
  game-icons.net (SVG, CC BY 3.0) albo Lucide, gdy ma lepszą ikonę.
- [ ] Ikony kategorii na liście treści: typ stworzenia, kategoria przedmiotu; małe i przygaszone jak
  ikony stanów. Ta sama ikona w pustym polu obrazka; kategoria spoza listy — ikona domyślna typu.

## Katalog świata

- [ ] Klik w tytuł okna podglądu albo przypiętej karty rozwija katalogi do entity i zaznacza ją
  w drzewie.

## Motyw

- [ ] Lista rozwijana chipa jest szeroka jak najszerszy element całej listy, nie tylko wyrenderowany —
  nie zmienia szerokości przy przewijaniu.
- [ ] Widoczny fokus klawiatury: jeden wygląd we wszystkich kontrolkach, które przyjmują fokus.
- [ ] Menu: skrót i strzałka podmenu kończą się na jednej krawędzi, podmenu nie nachodzi na menu
  (sprawdzić w Galerii, poprawić, jeśli trzeba).
- [ ] Szkło palety: krycie zabarwienia wybrane przez autora z renderów całego okna 1920×1080.

## Porządki

- [ ] Powody odrzucenia paczki i wpisu po polsku; błąd JSON nazywa pole.
- [ ] Nieaktualne komentarze: `CampaignRowViewModel`, `PanelCatalog`, `AppShellView.axaml`.
