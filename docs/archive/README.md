# Archiwum

Dokumenty sprzed przebudowy obiegu pracy. Nie opisują dzisiejszego stanu i nie obowiązują; zostają
jako materiał źródłowy. Przy zwykłej pracy ich nie czytaj — zajrzyj tu tylko wtedy, gdy konkretne
pytanie („dlaczego to jest tak zrobione?”) wymaga szczegółów, których nie ma w `docs/`.

- `architecture.md` — dawny projekt docelowy (formuły, sloty, dokument, dodatki — w szczegółach)
- `decisions.md` — pełny rejestr rozstrzygnięć z argumentami
- `zadania/zakladki-tresci.md` — projekt kart potwora i przedmiotu (sekcja *C*)
- `collaboration.md`, `code-state.md`, `tasks.md` — dawny obieg pracy, stan kodu i kolejka
